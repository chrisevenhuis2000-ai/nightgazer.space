# Hooks en 3D: concepten (fase 2)

Proef voor nightgazer-social (onderzoek: `docs/onderzoek-hooks-en-3d.md`, PR #133). Drie onderwerpen, elk met twee haken, in de huisstijl `reel-uitleg` met nieuwe 3D-bouwstenen (`scenes/_kit2.js`: atmosfeer met tegenlicht, terminator, NASA-texturen met dag/nacht, log-zoomcamera, haakkaart).

| nr | onderwerp | categorie | haak |
|---|---|---|---|
| NG-9301 | Voyager 1, een lichtdag | snap het | A tijd: "Woensdag is Voyager 1 een hele lichtdag ver." |
| NG-9302 | idem | snap het | B jij: "Een bericht naar Voyager 1 is straks een dag onderweg." |
| NG-9303 | de hoorns van Venus | vannacht | A onmogelijk beeld: "Dit is geen maan." |
| NG-9304 | idem | vannacht | B tijd en plek: "Vrijdagochtend zie je Venus laag in het zuidoosten." |
| NG-9305 | radarsatelliet (Electron) | lancering | A tegen-feit: "Deze satelliet kijkt dwars door wolken heen." |
| NG-9306 | idem | lancering | B tijd: "Deze week: een satelliet die door wolken kijkt." |

`node bouw.mjs` maakt `concepten.yaml` uit `scenes/`. Schets: `npm run vrij:schets -- concepten.yaml NG-930x` in nightgazer-social. Niet voor het plan; nummers NG-930x alleen voor deze proef.
